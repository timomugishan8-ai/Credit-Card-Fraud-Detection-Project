# Dataset Overview

Dataset Name:
Credit Card Fraud Detection

Author:
Bhadra Mohit

Source:
Kaggle

Target Variable:
IsFraud

0 = Legitimate Transaction

1 = Fraudulent Transaction

---

## Features

| Column | Description | Type |
|---------|-------------|------|
| TransactionID | Unique identifier | Integer |
| TransactionDate | Date and time of transaction | Datetime |
| Amount | Transaction amount | Float |
| MerchantID | Merchant identifier | Integer |
| TransactionType | Type of transaction | Categorical |
| Location | Transaction city | Categorical |
| IsFraud | Fraud label | Binary |
